# 自建手机号验证码登录 + 数据库会话，不采用 Better Auth 手机号插件

M1 实测 Better Auth 1.7 的手机号插件：手机号以明文存入 user 表并要求临时邮箱，验证码没有"每手机号每小时/每天""每 IP"限流，也没有可挂载邀请码门槛的位置。这与已确认的手机号 HMAC 索引 + 加密存储（D9）及限流/邀请码要求（D6）冲突。因此改为自建：验证码仅存 HMAC，会话令牌为随机 32 字节、仅存 SHA-256、通过 httpOnly Cookie 传递，邀请码在注册事务内原子核销。代价是认证代码由我们自己维护，因此全部行为都有集成测试（见 `tests/integration/auth.test.ts`）；若将来需要微信登录或多因素认证，应重新评估成熟认证库。
