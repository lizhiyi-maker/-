# 隐私、保留与删除

> 本文是工程设计，不是法律意见。标"待核实"的条目需法务/平台确认后才能写入用户界面文案。

## 1. 归属与访问
所有档案、消息、文件、任务、报告、导出、下载都校验用户归属；后台任务执行时同样校验。管理员默认不能浏览完整聊天；用户反馈时可主动附上片段；管理操作写审计记录。

## 2. 保留（初始建议，待你确认）
| 数据 | 规则 |
|---|---|
| 原图（已确认批次） | 立即停止访问，24 小时内清理在线文件 |
| 未确认/失败的上传 | 7 天清理 |
| 整理后的聊天与证据 | 保留至用户删除 |
| 短信验证码 | 5 分钟有效，仅存哈希，用后作废 |
| 应用日志 | 30 天；**不含**聊天正文、验证码、密钥 |
| 账户删除 | 立即停用并阻止新任务；立即删除在线数据（M5a 实现：同一流程内完成，中断时 worker 每 5 分钟继续，24 小时是上限） |
| 备份 / 对象存储历史版本 / 恢复后的删除重放 | **待核实**，不宣称瞬时彻底删除 |
| AI 服务商留存 | **待核实**（百炼的留存条件），未核实前不承诺任何删除行为 |

## 3. 存储与传输
文件放私有存储，仅通过短时有效签名链接访问；手机号 HMAC 索引 + 应用层加密；聊天正文依赖托管库与对象存储的静态加密（需用于分析，不做应用层加密——这是有意识的风险接受，写入部署文档）。

## 4. 数据使用
默认不使用真实用户聊天训练或评测产品；开发与评测使用模拟资料。支持用户导出自己的结构化资料与聊天文本。

## 5. 合规核实清单（待核实）
个人信息保护法下聊天内容的敏感性与单独同意、向第三方（模型服务商）委托处理的告知与协议、个人信息保护影响评估、生成式 AI 服务与深度合成相关备案/登记要求、ICP 备案、短信签名与模板审核、成年人确认方式、上传他人聊天的权利提示。

## 5a. 导出与账户删除（M5a 实现）
- **导出**：登录用户在“我的”页下载 JSON（`/api/export`），单个对象的可读聊天文本在其“聊天资料”页（`/api/export/people/[id]/chat`）。只含本人已保存的数据；不含手机号、验证码、会话令牌、原图及存储路径、未保存的暂存消息。导出行为写审计（只记数量）。
- **账户删除**：用户输入确认文字后，先在一个事务内置“删除中”并清除全部会话（立即不能登录、不能发起新任务；管理员也不能恢复），再按删除围栏删除全部对象及派生数据、删除原图文件、删除账户行（偏好、额度流水、同意记录、邀请码核销随之级联删除）。只保留“开始”“完成”两条审计，含用户 ID 与对象数量，不含手机号、昵称或内容。唯一的启用管理员不能删除自己。
- 同一手机号之后再注册是全新账户（需要邀请码）。邀请码的已用次数不回退。
- 界面如实说明：只保证我们自己系统内的在线数据；备份、对象存储历史版本、AI 服务商侧留存**待核实**，不作承诺。

## 6. 删除流程
见 [state-machines §5 删除围栏](./state-machines.md)。可删除粒度：单批资料、对象、账户；关联文件与派生结果（消息、证据、报告、快照、时间线）一并处理；运行中任务取消或失效。
