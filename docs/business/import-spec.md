# 聊天导入规范

决策依据：[ADR-0002](../adr/0002-message-revisions-and-evidence-references.md)、[ADR-0003](../adr/0003-confirmation-is-the-point-of-no-return-for-screenshots.md)。批次状态见 [state-machines](./state-machines.md)。

## 1. 统一消息结构
所属用户、对象、平台（微信/抖音/其他）、导入批次、发言人（我/对方/未确认）、内容、消息类型（文本/图片/语音/系统/其他）、**时间**与**时间精度**（秒/分/日期/仅顺序/未知）、顺序号、原始出处（批次+图片序号+区域，或文本行号）、识别状态（已识别/不确定/用户已改）、修订号。

## 2. 原则
- 不猜测：缺失的时间、看不清的文字、未提供内容的语音/图片，一律标"未知/不确定"，不补全。
- 无可靠时间 ⇒ 不计算回复间隔。
- 首次导入必须由用户确认"我/对方"，不得仅凭气泡颜色/位置决定。
- 用户可编辑所有识别文字；每次编辑产生新修订。

## 3. 导入流程
选择来源 → 上传或粘贴 → 识别整理 → 确认"我/对方" → 集中处理不确定内容 → 确认保存。
- 批内可交换发言人，交换前显示受影响的消息数与已有关联（如证据、重叠判定）。
- 上传、识别、确认进度存服务端；刷新后恢复；失败按项重试。
- 确认页明确提示：确认后原图将被删除，无法重新识别。

## 4. 重叠与重复
- **截图重叠**：相邻/相近截图的尾首若有连续的相同消息序列（内容+发言人，时间一致或未知），按序列匹配合并，而不是逐条按内容去重。
- **保留真实重复**：同一发言人连续发送相同内容（如连发两次"哈哈"），若不属于重叠序列，必须保留。
- **跨批次**：新批次与已确认消息比较，发现重叠序列时提示并默认合并，由用户确认；不得累计同一段聊天两次。
- **重复上传**：同一文件（哈希相同）重复上传提示并跳过。

**已知限制（M2a）**：重叠检测只能看到"内容、发言人、时间"。若已保存的聊天里本来就有一段与新资料完全相同的连续序列（例如两次一模一样的"早/早呀"对话），仍会被提示为重复，由用户在保存时选择"合并"或"全部保留"，系统不替用户决定。发言人未确认的消息不参与重叠判断。

## 5. 资料类型
用户可标记：**连续聊天** / **精选片段** / **不确定**。精选片段与不确定资料可支持具体表达分析，不得直接推断整段主动频率与稳定性（规则见评分文档 §3）。

## 6. 解析器扩展
文本/导出文件通过 `Parser` 接口接入：声明 `id`、`platform`、`detect(input)`、`parse(input)`。**只有存在明确格式说明与 `samples/` 测试样本的解析器才在界面中声明"支持"**，其余统一走"通用粘贴文本"（逐行启发式 + 必须用户确认发言人）。首批：通用粘贴文本 `generic-text-v1`（样本见 [samples/](../../samples/README.md)，支持"发言人 时间"换行接内容与"[日期 时间] 发言人：内容"两种格式）；微信/抖音导出文件格式在拿到真实格式样本后再声明。

## 7. 截图导入与识别（M2b）
- **上传**：逐张上传（每张独立成功/失败/重试，进度在服务端）。按文件头判断 PNG/JPEG/WebP，单张 ≤ 8 MB，单批 ≤ 30 张；同一对象下（含已保存、原图已删除的批次）相同哈希的文件提示并跳过。上传不识别、不扣额度。
- **开始识别**：用户点击才提交；按张数一次性预留识别额度（不足则整体拒绝），逐张入队，由独立 worker 执行。离开页面后继续，刷新或重启后进度从服务端读取。
- **轮次**：每次“开始识别/重试失败项”为一轮。一轮结束后按成功张数结算，其余退还；失败项重试开新一轮，只为失败的张数预留，因此每张最多被扣一次。
- **整合**：所有截图都结束（成功/失败/跳过）且没有待处理的失败项时，按上传顺序整合为暂存消息；相邻截图重叠的部分只保留一份（规则同 §4）。有失败项时先由用户选择“重试”或“跳过失败的，继续”；全部失败时不能跳过。
- **身份**：识别只给出原始标签（如名字或左/右侧），“我/对方”仍由用户确认，不凭气泡颜色或位置决定。
- **失败与超时**：服务商失败不扣额度；排队/运行超过 15 分钟没有结果的任务由清理任务判为失败并退还。

## 8. 原图生命周期
确认保存时即撤销访问（旧签名链接立即失效），文件由 worker 每小时物理删除（目标 24 小时内）；未确认的批次 7 天后连同原图清理；没有记录且超过 1 小时的孤儿文件也会被清理。截图记录保留（仅哈希、大小等元数据，无图片内容）用于查重。分析引用整理后的消息及上下文，不依赖原图。

确认页必须提示：保存后原图将被删除，无法重新识别（ADR-0003）。查看原图只能通过登录状态下的短时（5 分钟）签名链接。
