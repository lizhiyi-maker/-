# 隐私政策与用户协议：事实清单（供你/法务起草）

> **这不是隐私政策，也不是法律意见。** 它只列“产品实际做了什么”，每条都能在代码或文档里找到出处，供起草人核对用。条款措辞、法律依据、适用范围、联系方式等由你/法务写。凡是我无法验证的事一律标“待核实”，不得写成承诺。
> 与 [备案与合规核实清单](./icp-and-compliance.md)（C12）配套。最后核对代码的日期：2026-11-18（M6b）。

## ⚠ 先看：一处“实际发送”与“用户看到的说明”不一致（需要你决定）

AI 服务同意文案（`src/domain/consent.ts`）写的是：发送“你已保存的聊天文字、线下事件的事实部分、**你的个人偏好**”，“事件里写下的个人感受不会发送”，“不会发送手机号和账号信息”。

但分析请求里还会带上**对象档案里的“感受备注”（`feelingsNote`）和“当前好感值”（`currentFeeling`）**（`src/server/analysis/service.ts` 取自 `person.feelingsNote`、最新一条好感记录，经 `src/server/analysis/pipeline.ts` 传给 `interpret`，百炼适配器会原样放进请求）。同意文案没有提到这两项，而用户可能以为“个人感受不发送”覆盖了它们。

可选做法（**我没有改，等你定**）：
- A. 停止发送这两项（分析里“用户体验”一栏就没有内容；报告里原本会把它们单列为“你的体验”）；
- B. 保留发送，并改同意文案如实写明（这属于文案实质修改，应把 `CONSENT_VERSION` 加 1，已同意的用户会被要求重新同意）。

在你决定之前，隐私政策不能写“个人感受不会发送”这类概括性说法。

## 1. 收集哪些数据

| 数据 | 来源 | 用途 | 存放 |
|---|---|---|---|
| 手机号 | 用户登录时输入 | 登录验证；管理员后台只显示脱敏号 | 数据库：HMAC 索引 + 应用层加密，**不存明文**。验证码只存哈希，5 分钟有效 |
| 邀请码使用记录 | 注册 | 内测准入与追溯 | 数据库 |
| 对象档案：昵称、关系阶段、好感值与变化记录、感受备注、偏好 | 用户填写 | 展示、分析、对比 | 数据库 |
| 聊天文字（含对方的发言）及其修订历史 | 用户粘贴、或由截图识别后用户确认 | 展示与分析 | 数据库（正文不做应用层加密，依赖库的静态加密，待核实） |
| 聊天截图原图 | 用户上传 | 识别 | 对象存储私有桶；**确认保存后立即停止访问，24 小时内清理**；未确认的 7 天清理 |
| 线下事件（事实与个人感受分开存放） | 用户填写 | 展示、分析（只发事实）、时间线 | 数据库 |
| 分析报告与快照、适配分 | 系统生成 | 展示、趋势、对比 | 数据库 |
| 额度流水、同意记录（文案版本、服务商、时间） | 系统 | 额度控制、合规留痕 | 数据库 |
| 模型调用用量（类型、模型名、token、耗时、成败、估算成本） | 系统 | 成本核算 | 数据库；**不含任何聊天内容**；账户删除后保留但不再关联用户 |
| 用户反馈（文字与用户主动粘贴的片段） | 用户提交 | 改进产品 | 数据库；账户删除时一并删除 |
| 审计记录（管理员操作、导出、账户删除开始/完成） | 系统 | 安全与追溯 | 数据库；只含用户 ID/数量/操作类型，**不含手机号、昵称或内容** |
| 应用日志 | 系统 | 排障 | 设计上不含聊天正文、验证码、密钥；保留 30 天为目标（需在日志服务配置，待核实） |
| 会话 | 登录 | 保持登录 | 数据库；14 天有效；账户删除时清除 |
| IP 地址 | 请求头 | 登录/验证码限流 | 只用于限流计数（数据库表，定期清理）；是否另在日志出现待核实 |

## 2. 发给哪些第三方

| 第三方 | 发送什么 | 触发 | 状态 |
|---|---|---|---|
| **AI 服务商：阿里云百炼（通义千问）**（候选，已有适配器，未联调） | 截图识别：截图图片。分析：已保存的聊天文字（含对方发言）、线下事件的**事实部分**、偏好；**另有感受备注与当前好感值（见页首的不一致）**。不发手机号与账号信息 | 用户同意后、用户点“开始识别/开始分析” | 服务商留存与使用条件**待核实**；同意文案已写明“不对服务商侧留存/删除作承诺” |
| **短信服务：阿里云短信** | 手机号 + 验证码（放在请求 URL 查询串，HTTPS 传输） | 用户请求验证码 | 签名/模板审核待办 |
| **对象存储：阿里云 OSS** | 截图原图（私有桶，服务端加密请求） | 上传截图 | 桶配置（私有、加密、版本控制、生命周期）待核实 |
| 托管数据库 | 全部上述数据库数据 | 持续 | 厂商、地域、静态加密、备份待核实 |

- 不使用真实用户聊天训练或评测产品（产品约束；评测只用虚构样本）。
- 没有广告、没有第三方统计/追踪脚本（**请起草人再对照最终前端确认**，我只查了本仓库代码）。
- 粘贴文本导入**不发送给 AI**；只有截图识别与关系分析会发送。

## 3. 用户能做什么

| 权利 | 产品里怎么做 | 限制 |
|---|---|---|
| 查看 | 对象、聊天、事件、报告都在界面里 | — |
| 导出 | “我的”页下载 JSON（`/api/export`）；每个对象的聊天文本 | 不含手机号、验证码、会话令牌、原图及存储路径、他人数据；整份在内存生成 |
| 更正 | 聊天消息、事件事实、对象档案可编辑（消息与事件事实保留修订历史，用于证据溯源） | 修订历史不能被抹掉 |
| 删除 | 单批资料、单个对象、整个账户（输入“删除我的账户”）。账户删除=立即停用并清除会话，立即删除在线数据（对象、消息与修订、事件、报告、偏好、额度记录、同意记录、原图文件） | **只保证我们自己系统内的在线数据**。备份、对象存储历史版本、AI 服务商侧留存**待核实，不作承诺**；恢复备份可能让已删除数据复活（无重放工具）；唯一的管理员不能删除自己；删除账户不需要再次验证（只需确认文字）；模型用量记录保留但已匿名 |
| 撤回 AI 同意 | **目前没有撤回入口**（同意按版本记录，文案升版本后需重新同意）；不同意则不能用截图识别与分析 | 是否需要撤回入口由你/法务定 |
| 对方（被聊天的人）行使权利 | **没有入口** | 见合规清单 C5 |

## 4. 产品的边界声明（可写入协议，须与产品一致）

- 分析是“对已有资料的整理”，不是对对方的评价；不做心理诊断；不展示成功概率或百分比；证据不足就标“资料不足”，不是低分。
- 适配分与排名使用**实验规则**，界面标注“实验规则”。
- 对方明确表示不希望联系后，报告只给“尊重边界”类建议。（已知限制：用户当面听到的拒绝如果只记成线下事件，不会触发停止推进建议。）
- 用户应只上传自己有权使用的资料；聊天含他人个人信息（合规清单 C8：界面尚无专门的权利提示）。
