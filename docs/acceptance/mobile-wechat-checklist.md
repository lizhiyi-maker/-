# 手机端与微信内置浏览器真机验收清单

> 自动化已经覆盖的是**设备模拟**（Playwright：iPhone 14 WebKit、Pixel 7 Chrome、桌面 Chrome），它不是真机：不含真实的软键盘、系统相册/相机、安全区、微信内核（iOS 为 WKWebView，Android 为微信自带内核）、真实网络。**下面每一项都需要你在真机上做**，结果记进表里（✅ 通过 ｜ ❌ 失败并写现象 ｜ — 不适用）。
> 前置：用一个**演示环境**（`APP_MODE=demo`，模拟短信/模型）或预发环境做；演示环境要能被手机访问（局域网 IP 或内网穿透）。**真实服务接入之前，这份清单只能验证界面与交互，不能验证真实短信、真实识别质量。**
> 微信内打开：把链接发到“文件传输助手”后点开，或用二维码。

## H. 自动化覆盖了什么（避免重复劳动）

- Playwright 三种视口跑过：登录、对象、导入、识别、分析、报告、对比、记录、导出、删除、反馈、后台（84 个用例通过）。
- 它**没有**覆盖：真实软键盘、相册/相机、系统深色/字体缩放、微信内核差异、真实网络、真实短信自动填充。
